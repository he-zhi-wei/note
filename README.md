## 整理约定

- 每门学科合并为一篇 Markdown，按知识点分节，不再逐图拆分。
- 手写内容按原意转录；明显的手误、笔误会在文中以「补充」或「注」的形式说明。
- 公式统一使用 LaTeX 语法（`$...$` 与 `$$...$$`），GitHub 可直接渲染。
- 原始照片仍保留在各自的原仓库中，作为对照来源。

## 笔记概览

### 信息论

信息量定义 → 熵 → 编码与前缀码 → 固定长度编码与整数编码。核心公式：`I = log2(1/p)`、`H = Σ p log2(1/p)`。

### 核反应堆物理

反应堆分类 → 放射性衰变与核素链 → 中子反应与 Q 值 → 微观/宏观截面 → 平均自由程。核心公式：`N(t) = N0 e^(-λt)`、`Σt = Nσt`、`x̄ = 1/Σt`。
